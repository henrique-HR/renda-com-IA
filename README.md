## 📋 Sobre o projeto

Landing page completa para o infoproduto **"Renda com IA — Do Zero ao Primeiro Pagamento"**, um guia digital de R$ 15 que ensina como gerar renda usando ferramentas de IA sem experiência prévia.

Esta página foi desenvolvida em parceria com **Claude (IA da Anthropic)** — eu defini a ideia, o produto, o conteúdo e todas as decisões criativas; o Claude foi o assistente de código que transformou essas ideias em HTML, CSS e JavaScript funcionando no ar. Saber usar IA como ferramenta de desenvolvimento é, hoje, uma habilidade real de mercado.

---

## 🤖 Como foi o processo de desenvolvimento com IA

O fluxo de trabalho foi totalmente colaborativo:

1. **Eu defini** — estrutura da página, seções, copy, paleta de cores e identidade visual
2. **Claude gerou** — o código HTML/CSS/JS com base nas minhas instruções e feedbacks
3. **Eu revisei e ajustei** — testei no browser, pedi correções, refinei detalhes
4. **Eu subi** — configurei o GitHub Pages e fiz o deploy final

> 💡 Este projeto demonstra domínio de **prompt engineering aplicado ao desenvolvimento front-end** — uma das habilidades mais valorizadas no mercado atual.

---

## ✨ Funcionalidades

- Design premium com paleta navy escuro e dourado
- Tipografia editorial com Google Fonts (Playfair Display + DM Sans)
- Animações de entrada com Intersection Observer API
- Smooth scroll nos botões de CTA
- Overlay de textura noise via SVG inline
- Seção de bônus com fases de prompts
- Garantia de 7 dias com seção dedicada
- Integração com Facebook Pixel para rastreamento de conversões
- Checkout via link externo (Kiwify)
- Layout responsivo para mobile e desktop

## 💡 O que eu aprendi construindo isso

- Criar layouts premium com CSS puro sem depender de frameworks
- Usar CSS custom properties (`--variáveis`) para manter consistência visual
- Implementar animações performáticas com `IntersectionObserver`
- Integrar rastreamento de marketing (Facebook Pixel) em página estática
- Usar IA como ferramenta real de desenvolvimento — descrevendo, revisando e iterando
- Publicar e manter um produto digital no ar via GitHub Pages
